## The word

> noddrift — nodding along to a conversation you stopped following three minutes ago.

## Run

```sh
python3 main.py
```

This writes the word and its definition to `/output/entry.txt`, reads it back to verify it
byte-for-byte, and prints its SHA-256. Standard library only.
